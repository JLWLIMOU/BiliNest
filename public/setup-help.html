还差一步：需要 Node.js

BiliNest 的本地服务由 Node.js 驱动。系统里没找到可用的 Node.js 18 或更高版本，所以这次没能启动。

方法一：命令行安装（推荐）

按 Win 打开开始菜单，输入 cmd，在「命令提示符」里粘贴下面这行并回车：

winget install OpenJS.NodeJS.LTS

方法二：官网下载安装

  1. 打开 nodejs.org 下载页；
  2. 下载 LTS 版本的 Windows 安装包（.msi），一路下一步即可。
安装过程中如果看到 Add to PATH 这个选项，请保持勾选。装好之后，重新双击桌面上的 BiliNest 快捷方式就行。

已经装过了？

如果你用的是绿色版 / 便携版 Node.js，它可能不在系统 PATH 里。把 node.exe 所在的文件夹加入 PATH 后重试即可；也可以在安装 Node.js 后，用命令 node -v 确认能输出版本号。
